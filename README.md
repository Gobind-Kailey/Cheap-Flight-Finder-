# Cheap-Flight-Finder-

• This project is for any flight enthusiasts or anyone is general looking for cheapflights. 

• In this project, I used the 'Sheety' API for retrieving data from a Google Sheet, which was initially populated with user preferences. 

• Below is the link to the Google Sheet:

• I used OOP as there are 6 files of code and it makes it easier to catch mistakes and create distinctions. 
• I also used environment variables for safety.
• The Amadeus API is used for finding the cheap flights. 
• The Twilio API is used to email the user cheap flights.
